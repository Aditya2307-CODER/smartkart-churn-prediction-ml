# SmartKart Churn Prediction – ML Pipeline

## Project Overview

This project focuses on predicting customer churn for SmartKart using a Machine Learning pipeline.

The notebook covers the complete workflow from data preparation and exploratory analysis to model training and evaluation.

## Objectives

- Analyze customer data
- Identify patterns related to customer churn
- Prepare data for Machine Learning
- Train a churn prediction model
- Evaluate model performance
- Generate predictions that can support business decisions

A churn prediction system can help SmartKart identify customers who may stop using the platform.

The predictions can support:

- Customer retention strategies
- Personalized offers
- Targeted marketing
- Customer engagement
- Revenue protection
